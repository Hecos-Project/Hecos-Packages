# Sounds Pack
Libreria aggiuntiva di suoni, notifiche e allarmi per Hecos.

## Installazione e Utilizzo
Una volta installato questo pacchetto, tutti i suoni verranno copiati automaticamente nella cartella di sistema centralizzata di Hecos:
`C:\Hecos\hecos\assets\sounds`

Questi suoni diventeranno **immediatamente disponibili per tutti i moduli Hecos** che fanno uso di effetti sonori (ad esempio le notifiche, le sveglie, il reminder, l'avvio del sistema, ecc.). 

Quando deciderai di disinstallare il pacchetto, i suoni verranno automaticamente rimossi senza intaccare i suoni predefiniti di Hecos.
