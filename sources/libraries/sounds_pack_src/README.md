# Hecos Sound Pack
Libreria audio con suoni, effetti e notifiche di sistema addizionali per Hecos.

## Installazione e Utilizzo
Una volta installato questo pacchetto, tutti i suoni verranno copiati o resi disponibili nella cartella dei suoni di sistema (o nella cartella predefinita per gli assets audio).

Questi suoni diventeranno **immediatamente disponibili per tutti i moduli Hecos**, in particolare per:
- **Il motore Hecos Flows** (il modulo automazioni per riprodurre suoni, allarmi e notifiche nei flussi, es. *onboarding*)
- Moduli per le notifiche, sveglie e reminder
- Avvio e segnali di sistema

*Nota per Hecos Flows: Alcuni template di default, come il flusso "onboarding", fanno uso di questi suoni. Se non li installi, potresti ricevere errori "file not found" durante la riproduzione.*
