# Contacts Plugin for Hecos

Full-featured Address Book plugin for Hecos. Stores contacts with rich metadata (multi-value phones/emails/socials, photo, birthday, tags, label color).

Features:
- LLM Tools to add, find, update and delete contacts.
- REST API for frontend integration.
- vCard import/export support.
- Native UI extension in the Central Hub.
- WhatsApp messaging integration.
