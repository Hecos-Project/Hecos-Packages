# Hecos Net Search

**Net Search** is the native Deep Search & Intelligence System App for Hecos. It provides uninhibited multi-engine web meta-search, Tor Dark Web (.onion) discovery, OSINT username lookup, media streaming, and file hunting without third-party Docker containers.

## Features
- **Clearnet Meta-Search**: Aggregated queries via SearXNG, DuckDuckGo, Brave, Mojeek, Qwant, Startpage, Yandex, Wikipedia, GitHub, Reddit.
- **Tor Dark Web (.onion)**: SOCKS5h privacy routing to Ahmia, TorDex, Phobos, OnionLand, Tor66, Excavator, Torch, and custom hidden directories.
- **Pure-Python Architecture**: 100% Docker-Free.
- **Built-in Tor Live Viewer**: Safely view `.onion` hidden services cross-browser with sub-resource proxying and Tor Browser launcher integration.
- **OSINT & Files**: Sherlock username lookup and filetype dorking (PDF, DOCX, EPUB, archives).
- **Bookmarks & Saved Links**: Tagged search bookmarks with full JSON export.
- **LLM Function Calling**: Direct AI integration for `/netsearch`, `/dark`, `/tor_new` and autonomous tool calling.
